為什麼需要無母數檢定？

參數檢定（t 檢定、F 檢定）假設母體為常態分布。當：
①母體明顯非常態（如報酬率有「肥尾」fat-tail）
②樣本數很小、無法靠中央極限定理補救
③資料只是次序尺度（ordinal）而非區間/比率尺度
→ 就改用「無母數檢定（distribution-free tests）」，不需假設母體分布形狀。
代價是：當常態假設確實成立時，無母數檢定的檢定力（power）較低，更容易犯型二錯誤（β↑）。因此「能用參數就用參數，無法用才換無母數」。

20.1 Wilcoxon 符號等級檢定（單一母體中位數）

適用時機

想檢定母體中位數 m 是否等於某假設值 m₀，但母體非常態或樣本小。唯一要求：母體分布連續且對稱。

步驟
  1. 計算差值 di = xi − m₀
  2. 去掉 di = 0 的觀測值；n = 剩餘樣本數
  3. 對 |di| 由小到大排名（同值取平均等級）
  4. 分別加總負差異的等級（T⁻）和正差異的等級（T⁺）
  5. 驗算：T⁻ + T⁺ = n(n+1)/2
  6. 檢定統計量 T = T⁺
THE WILCOXON SIGNED-RANK TEST
T = T⁺（正差異的等級總和）

小樣本（n ≤ 10）：用統計軟體或特別表查 p 值。

大樣本（n ≥ 10）：T 的抽樣分布近似常態：
μT = n(n+1)/4
σT = √[n(n+1)(2n+1)/24]
z = (T − μT) / σT
T 不是 t 分布的 t 值！這個 T 是等級總和，是全新的統計量，要對應常態分布（z）。

假設形式

雙尾右尾左尾
H₀: m = m₀
Hₐ: m ≠ m₀		H₀: m ≤ m₀
Hₐ: m > m₀		H₀: m ≥ m₀
Hₐ: m < m₀
直覺：如果中位數真的等於 m₀，則正差異與負差異應各占一半，T⁺ ≈ T⁻ ≈ n(n+1)/4。若 T⁺ 大很多，代表大多數觀測值都在 m₀ 右邊 → 中位數可能 > m₀。

20.2 兩樣本 Wilcoxon 檢定

配對樣本：Wilcoxon 符號等級檢定

參數：中位數差異 mD（D = X − Y）
步驟：先計算每對的差值 di = xi − yi，其餘步驟與 20.1 完全相同。

假設形式：H₀: mD = 0 vs Hₐ: mD ≠ 0（或 > 0 或 < 0）

獨立樣本：Wilcoxon 等級和檢定（Mann-Whitney）

步驟
  1. 將兩組合併，對全部 n = n₁ + n₂ 筆資料由小到大排名
  2. 同值取平均等級
  3. 分別計算第1組等級和 W₁、第2組等級和 W₂
  4. 驗算：W₁ + W₂ = (n₁+n₂)(n₁+n₂+1)/2
  5. 檢定統計量 W = W₁
THE WILCOXON RANK-SUM TEST（大樣本：n₁≥10 且 n₂≥10）
μW = n₁(n₁+n₂+1) / 2
σW = √[n₁n₂(n₁+n₂+1) / 12]
z = (W − μW) / σW
等級和檢定把兩組資料全部混在一起排名，不是分開排！若中位數相同，兩組應該交錯出現，等級和差不多；若某組中位數較大，那組的觀測值通常佔據較高等級。

20.3 Kruskal-Wallis 檢定（三組以上中位數）

這是 ANOVA（F 檢定）的無母數版本。ANOVA 假設各組都是常態且變異數相等；當這些假設不成立時，改用 Kruskal-Wallis。

步驟

  1. 將全部 c 組資料合併，共 n = Σnᵢ 筆，由小到大排名（同值取平均等級）
  2. 計算各組的等級和 Rᵢ
  3. 計算 H 統計量
  4. p 值查 χ² 分布表，df = c − 1
  5. 永遠是右尾（right-tailed）檢定
THE KRUSKAL-WALLIS TEST STATISTIC H
H = [12 / (n(n+1))] × Σ(Rᵢ² / nᵢ) − 3(n+1)

其中 Rᵢ = 第 i 組等級和，nᵢ = 第 i 組樣本數，n = Σnᵢ，c = 組數

當 nᵢ ≥ 5 時，H ~ χ²(df = c−1)

Kruskal-Wallis 只能告訴你「有沒有至少一組中位數不同」，無法指出是哪兩組不同（類似 ANOVA 的整體 F 檢定，需要事後多重比較才能知道細節）。
計算 H 的關鍵：先算每組的 Rᵢ²/nᵢ，再全部加總。容易算錯的地方是 n 是「全部資料總數」不是組數 c。

20.4 Spearman 等級相關檢定

Pearson 相關係數衡量「線性」關係；Spearman 等級相關係數衡量「單調」關係（x 越大，y 是否也越大？），且不需要常態假設，是 Pearson 的無母數版。

計算步驟

  1. 對 x 變數排名（從小到大），得到各觀測的 x 等級
  2. 對 y 變數排名（從小到大），得到各觀測的 y 等級
  3. 計算每對的等級差 dᵢ = (x 等級) − (y 等級)
  4. 計算 Σdᵢ²（驗算：Σdᵢ 應 = 0）
  5. 代入公式求 rS
THE SPEARMAN RANK CORRELATION TEST
rS = 1 − 6Σdᵢ² / [n(n²−1)]

n ≤ 10：用軟體或特別表查 p 值。
n ≥ 10：rS 近似常態，檢定統計量：
z = rS × √(n−1)
Spearman 係數公式中的「6」是固定常數，不是樣本相關的數字！公式記法：rs = 1 − 6Σd²/[n(n²−1)]。

假設形式

雙尾（是否有相關）右尾（是否正相關）左尾（是否負相關）
H₀: ρS = 0
Hₐ: ρS ≠ 0		H₀: ρS ≤ 0
Hₐ: ρS > 0		H₀: ρS ≥ 0
Hₐ: ρS < 0

20.5 符號檢定（Sign Test）

用於「配對次序尺度資料」，例如讓客戶比較新舊產品並評分（1~5分），但這種分數的差距沒有意義（5分和4分的差≠1分和2分的差）。符號檢定只看「誰比較高」（正號 + 或負號 −），完全忽略差異大小。

步驟

  1. 對每對計算差值：第一個 > 第二個 → 記「+」；第一個 < 第二個 → 記「−」；相等 → 丟棄（不計入 n）
  2. n = 有效配對數（非零差異數）
  3. x = 正號（+）的個數
  4. p̄ = x/n（正號比例）
  5. 當 n ≥ 10，用常態近似
THE TEST STATISTIC FOR THE SIGN TEST（n ≥ 10）
p̄ = x/n（x = 正號個數）
z = (p̄ − 0.5) / (0.5/√n)

這實際上是比例檢定：H₀假設 p = 0.50（正負號各半）

假設形式

雙尾右尾（正號較多）左尾（負號較多）
H₀: p = 0.50
Hₐ: p ≠ 0.50		H₀: p ≤ 0.50
Hₐ: p > 0.50		H₀: p ≥ 0.50
Hₐ: p < 0.50
符號檢定 vs Wilcoxon 符號等級檢定：當資料是區間/比率尺度（有具體數字），優先用 Wilcoxon 符號等級檢定，因為它同時考慮差異的方向和大小，檢定力更強。符號檢定只適合純次序資料或差異大小無意義的情況。

20.6 Wald-Wolfowitz 連串檢定（Runs Test）

想知道一個序列是否「隨機」，例如：機器填充是否有規律地忽多忽少？股票漲跌是否有固定型態？此檢定不看數值大小，只看「同類連在一起的長度」是否異常。

核心概念

連串（Run）：序列中同一類別的不間斷連續段。
例：OOOUUOOOUU → 有 4 個連串（OOO、UU、OOO、UU）
太少連串 → 物品被分堆，有規律趨勢；太多連串 → 交替太頻繁，也異常。
因此連串檢定永遠是雙尾檢定。
THE TEST STATISTIC FOR THE WALD-WOLFOWITZ RUNS TEST（n₁≥10, n₂≥10）
μR = 2n₁n₂/n + 1
σR = √[2n₁n₂(2n₁n₂−n) / (n²(n−1))]
z = (R − μR) / σR

R = 連串總數；n₁, n₂ = 兩類別個數；n = n₁ + n₂

中位數上下連串法

當資料是連續數值時，以樣本中位數為界線，高於中位數記 A、低於中位數記 B（等於中位數的觀測值丟棄），再對 A/B 序列做連串檢定。
→ 太少連串（R 遠小於 μR）暗示有趨勢（前期全 A 後期全 B 或相反）。
→ 太多連串暗示有週期性波動。

各方法總覽比較
